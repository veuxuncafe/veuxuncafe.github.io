logits（得分）

logits 概率与信息论
\(z_j\)
第 j 类的原始得分，可正可负
\(K\)
类别数（语言模型里是词表大小 V）
\[ z \;=\; \big[\,W h + b\,\big]\in\mathbb{R}^{K} \]

神经网络最后一层线性输出的实数得分，尚未归一化：不要求和为 1，也没有上下界。

  • 只有同一次前向内部的 logits 之间可比较；不同输入的 logits 绝对值没有意义。
  • 语言模型的 logits 形状是 [batch, seq, vocab]；而 DPO 代码里那个叫 logits 的变量是「二元分类的 logit」，是一个标量——同名不同物。

模型每次前向的输出；π_θ(y|x) 要先由 logits 经 softmax 再按 token 连乘。

相关：softmax、温度、对数域技巧 log-sum-exp

softmax

softmax function 概率与信息论
\(z\)
logits 向量
\(\mathrm{softmax}(z)_i\)
第 i 类的概率
\[ \mathrm{softmax}(z)_i=\frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}} \]

先取指数、再归一化：把任意实数得分变成概率分布（各分量在 (0,1)、和为 1）。

  • 平移不变：\(\mathrm{softmax}(z+c)=\mathrm{softmax}(z)\)，所以起作用的只有得分之间的差。
  • \(K=2\) 时它就是 sigmoid：\(\mathrm{softmax}([z_w,z_l])_w=\sigma(z_w-z_l)\)。
  • 实现必须先减最大值，否则指数上溢。

语言模型的下一个 token 分布；DPO 里的最优策略也是回答空间上的 softmax。

相关：logits（得分）、sigmoid（logistic 函数）、温度、对数域技巧 log-sum-exp

sigmoid（logistic 函数）

logistic sigmoid 概率与信息论
\(\sigma(z)\)
概率，值域 (0,1)
\(\sigma(-z)=1-\sigma(z)\)
对称性
\[ \sigma(z)=\frac{1}{1+e^{-z}},\qquad \frac{d\sigma}{dz}=\sigma(z)\big(1-\sigma(z)\big) \]

把任意实数压到 (0,1)，用作二分类概率。它等于 \(K=2\) 的 softmax。

  • 「sigmoid」是一族形状（tanh、arctan、erf 都算），logistic 是其中特定的一个；在机器学习里不加限定时 sigmoid 就指 logistic。
  • 它区别于其它 S 形函数的本质是：反函数是 logit（对数几率），所以能做「奖励差 = 对数几率」的解释。

Bradley–Terry 的连接函数，因此直接出现在 DPO 损失里。

相关：softmax、二元交叉熵 BCE、Bradley–Terry 模型

softplus

softplus 概率与信息论
\(\zeta(z)\)
值域 (0,∞)
\(\zeta'(z)=\sigma(z)\)
导数是 sigmoid
\[ \zeta(z)=\log\big(1+e^{z}\big) \]

ReLU 的光滑版本，处处可导、值域 \((0,\infty)\)。

  • 它不是概率函数（值域不是 (0,1)），不要和 sigmoid 混。
  • 数值上要用 \(\max(z,0)+\log(1+e^{-|z|})\)，直接算 \(\log(1+e^z)\) 在 z 很大时会先上溢。

\(-\log\sigma(z)=\mathrm{softplus}(-z)\)，这就是实现里 \(-\texttt{F.logsigmoid}\) 的由来。

相关：sigmoid（logistic 函数）、二元交叉熵 BCE、对数域技巧 log-sum-exp

二元交叉熵 BCE

binary cross-entropy / log loss 概率与信息论
\(y\in\{0,1\}\)
真实标签
\(\hat y\in(0,1)\)
预测概率
\[ \mathcal{L}_{\mathrm{BCE}}(\hat y,y)=-\Big[y\log\hat y+(1-y)\log(1-\hat y)\Big] \]

二分类的负对数似然：它衡量「你给正确类别的概率有多低」。\(y=1\) 时就是 \(-\log\hat y\)。

  • 它是 proper scoring rule，所以奖励「诚实的概率」，而不是「拍胸脯的 0.99」。
  • 互斥多类要用 softmax 交叉熵，不能用 V 个 sigmoid；后者允许概率加起来不等于 1。
  • 实现要用 logits 版本（\(\texttt{binary\_cross\_entropy\_with\_logits}\)），不能写 \(\log(\mathrm{sigmoid}(z))\)。

DPO 损失就是这个式子、标签恒为 1；gold NLL 是它的 K 类推广。

相关：熵、交叉熵与 KL、DPO 损失、数值稳定性（上溢／下溢）

熵、交叉熵与 KL

entropy / cross-entropy / KL divergence 概率与信息论
\(H(p)\)
熵：p 自身的不确定性
\(H(p,q)\)
交叉熵：真实是 p、却按 q 编码的平均代价
\(D_{\mathrm{KL}}(p\|q)\)
KL：用错分布的额外代价
\[ H(p,q)=H(p)+D_{\mathrm{KL}}(p\|q) \]

交叉熵 = 熵 + KL。硬标签（one-hot）时 \(H(p)=0\)，所以交叉熵与 KL 数值完全相等——这是「感觉它们差不多」的精确来源。

  • RLHF 里的参考分布不是 one-hot，此时 \(D_{\mathrm{KL}}(\pi\|\pi_{\mathrm{ref}})=H(\pi,\pi_{\mathrm{ref}})-H(\pi)\)，不能用「到参考模型的交叉熵」替代 KL——那会连策略自身的熵一起压，把模型推向确定化。
  • 单位：以 2 为底是 bits，以 e 为底是 nats；语言模型与 RLHF 全程用 nats。

\(\log(\pi_\theta/\pi_{\mathrm{ref}})\) 这个到处出现的对数比就是 KL 的被积函数。

相关：二元交叉熵 BCE、最大似然估计 MLE、温度

最大似然估计 MLE

maximum likelihood estimation 概率与信息论
\(\theta\)
待估参数
\(\log p_\theta(y_i\mid x_i)\)
第 i 条数据的对数似然
\[ \hat\theta=\operatorname*{arg\,max}_{\theta}\;\sum_i \log p_\theta(y_i\mid x_i) \]

让观测到的数据在模型下概率最大；等价于最小化与经验分布的交叉熵。

  • 一般没有闭式解——logistic 回归就是标准反例，必须迭代。
  • 最大化似然不等于最大化准确率；样本少时容易过拟合。

DPO 的训练就是 Bradley–Terry 偏好模型的 MLE；RLHF 里拟合奖励模型也是 MLE。

相关：二元交叉熵 BCE、Bradley–Terry 模型、闭式解

Bradley–Terry 模型

Bradley–Terry model 概率与信息论
\(y_w\)
偏好回答／正确回答（DPO 原文 chosen）
\(y_l\)
非偏好回答／负例回答（DPO 原文 rejected）
\[ \Pr(y_w\succ y_l\mid x)=\sigma\big(r(x,y_w)-r(x,y_l)\big) \]

用「潜奖励 + logistic 噪声」建模人类偏好：偏好概率等于奖励差的 sigmoid。

  • 它假设偏好可传递、噪声独立同分布、且只有一个潜标量——现实中这些都不严格成立。
  • 奖励只在同一条 prompt 内的差可识别；跨 prompt 存在未知的常数偏移。

DPO 推导第五步代入的就是它，配分函数在相减时对消。

相关：sigmoid（logistic 函数）、DPO 损失、margin 与 margin loss

温度

temperature 概率与信息论
\(T\)
温度，T→0 越尖，T→∞ 越平
\[ \mathrm{softmax}(z/T)_i=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}} \]

温度控制分布的锐度：越小越接近 argmax（硬），越大越接近均匀（软）。

  • 把 logits 乘一个系数等价于把温度除以它，所以「缩放 logit」和「调温度」是同一件事。
  • DPO 的 \(\beta\) 就是温度，不是间隔阈值；把它当 margin 调会调错方向。

\(\pi^*(y\mid x)\propto\pi_{\mathrm{ref}}(y\mid x)\exp(r/\beta)\) 里的 β 与损失里的 β 是同一个。

相关：softmax、DPO 损失

闭式解

closed-form solution 优化与凸性
\(a,b,c\)
二次方程的系数
\[ x=\frac{-b\pm\sqrt{b^2-4ac}}{2a} \]

把已知量代进一个显式公式就能算出答案，不需要迭代逼近。它说的是答案的形式，不是难度。

  • 存在 ≠ 可计算：DPO 的最优策略有闭式形式，但里面的配分函数 \(Z(x)\) 对全部回答求和，算不出来。
  • 闭式不一定快：\((A^{\top}A)^{-1}A^{\top}b\) 是 O(n³)，数值上往往不如迭代法。
  • 五次及以上的一般多项式没有根式解（Abel–Ruffini），这是被证明的不可能，不是「还没找到」。

RLHF 目标的最优策略有闭式解 → 这是 RL 循环能被消掉的原因；但 DPO 损失的最优参数没有闭式解，仍然 SGD。

相关：凸性与唯一最优、KKT 条件、配分函数与它的对消、最大似然估计 MLE

凸性与唯一最优

convexity 优化与凸性
\(f\)
目标函数
\(\lambda\in[0,1]\)
内插系数
\[ f\big(\lambda x+(1-\lambda)y\big)\;\le\;\lambda f(x)+(1-\lambda)f(y) \]

凸目标 + 凸约束 ⇒ KKT 条件既必要又充分，驻点就是全局最优。这是「直接上拉格朗日」的合法性依据。

  • 要严格凹才有唯一最优，否则可能一整段都是最优解。
  • 神经网络的损失一般非凸，此时 KKT 只是必要条件，不能用来宣称找到全局最优。

DPO 逐 prompt 的目标含负熵项、严格凹，约束是概率单纯形（凸）——所以第一步的推导是真解而非启发式。

相关：KKT 条件、拉格朗日乘子、闭式解

拉格朗日乘子

Lagrange multiplier 优化与凸性
\(\lambda\)
约束的乘子（影子价格），对每个约束单独取
\(g_i(x)=0\)
等式约束
\[ \mathcal{L}(x,\lambda)=f(x)+\sum_i\lambda_i\,g_i(x) \]

把约束吸收进目标函数，用乘子表示「放松这个约束值多少」。

  • 乘子是对每个约束单独取的，不是全局一个常数。
  • 只有在约束资格条件（constraint qualification）满足时，KKT 才是必要条件。

DPO 推导公式 (4)：把归一化约束 \(\sum_y\pi(y\mid x)=1\) 吸收进去，解出 λ 后由归一化定死。

相关：KKT 条件、凸性与唯一最优

KKT 条件

Karush–Kuhn–Tucker conditions 优化与凸性
\(\nabla f\)
目标梯度
\(\lambda_i\ge 0\)
不等式约束的乘子非负
\(\lambda_i g_i=0\)
互补松弛
\[ \nabla f(x^*)+\sum_i\lambda_i\nabla g_i(x^*)=0,\qquad \lambda_i\ge 0,\qquad \lambda_i g_i(x^*)=0 \]

约束优化最优性的一阶条件。互补松弛 \(\lambda_i g_i=0\) 说的是：没有起作用的约束，乘子为 0。

  • 凸问题里它必要且充分；非凸问题里只是必要。
  • 「互补松弛」是理解「投影不活跃就不动手」的关键。

逐题投影里「投影系数为 0 的不活跃对照」正是互补松弛的表现：该题本来就没被伤到，约束不起作用。

相关：拉格朗日乘子、凸性与唯一最优、向半空间投影

向半空间投影

projection onto a half-space 优化与凸性
\(g\)
约束的法方向（也是该点上升最快的方向）
\(x'\)
投影后的点
\[ g^{\top}x>b\;\Longrightarrow\;x'=x-\frac{g^{\top}x-b}{\|g\|^{2}}\,g \]

把点投到满足 \(g^{\top}x\le b\) 的最近位置：做法是沿 g 方向删掉越界的那一部分分量。

  • 多个约束时不是逐条投影一次就对，要迭代（Dykstra／POCS）或解二次规划。
  • 投影的对象是「参数位移」，不是原始梯度——和梯度裁剪是两回事：裁剪限范数（对所有方向一视同仁），投影只删有害方向。

逐题投影的闭式解就是 \(b=0\) 的情形：把更新里会造成某道源题一阶恶化的方向分量减掉。

相关：KKT 条件、二次规划 QP、一阶近似（线性化）

一阶近似（线性化）

first-order approximation 优化与凸性
\(\nabla f(x)\)
当前点的梯度
\(\Delta\)
参数更新量
\[ f(x+\Delta)\;\approx\;f(x)+\nabla f(x)^{\top}\Delta \]

用梯度预测小步长带来的函数变化——梯度法的一切依据。

  • 只在小步长下准。一阶不增不保证有限步不增，因为二阶及以上项被丢掉了。
  • 所以「一阶预测改善」和「实际行为改善」是两件事，必须分别测量。

逐题投影的保护条件 \(g_i^{\top}\Delta\le 0\) 就是「一阶预测下这道题不恶化」；这条边界是你们报告里明确写出的限制。

相关：向半空间投影、梯度下降与 Adam

二次规划 QP

quadratic programming 优化与凸性
\(c\)
候选更新（Adam 给的）
\(A\Delta\le b\)
线性约束组
\[ \min_{\Delta}\ \tfrac12\|\Delta-c\|^{2}\quad\text{s.t.}\quad A\Delta\le b \]

二次目标 + 线性约束。多个半空间约束下「找离候选点最近的可行点」就是它的特例。

  • 约束数变大时求解成本上升；实践里常用迭代投影近似而不精确求解。
  • 约束互相矛盾时可行集为空，需要松弛或优先级。

多道保护题同时约束时，逐题投影求解的就是这个；单约束时退化成闭式投影。

相关：向半空间投影、KKT 条件

梯度下降与 Adam

gradient descent / Adam 优化与凸性
\(m_t,v_t\)
一阶、二阶矩估计
\(\hat m_t,\hat v_t\)
偏差修正后的估计
\(\eta,\epsilon\)
学习率、数值稳定项
\[ \theta_{t+1}=\theta_t-\eta\,\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon} \]

用梯度的历史一阶／二阶矩做逐参数自适应缩放：梯度大的参数步子自动缩小。

  • 逐参数缩放带来近似尺度不变性（梯度整体乘 c，更新几乎不变）。
  • Adam 只看到批次的平均梯度，结构上无法知道「哪一条样本被牺牲」——这是平均改善掩盖个别退化的机制来源。

环节 A：普通优化与逐题投影的对照基线；投影是叠在 Adam 候选更新之上的修正层。

相关：一阶近似（线性化）、反向传播

链式法则

chain rule 微积分与自动微分
\(\partial z/\partial y\)
局部导数（雅可比）
\(\partial y/\partial x\)
下一层局部导数
\[ \frac{\partial z}{\partial x}=\frac{\partial z}{\partial y}\cdot\frac{\partial y}{\partial x} \]

复合函数的导数 = 各层局部导数依次相乘。反向传播的全部内容就是它。

  • 矩阵情形是雅可比相乘，顺序不能颠倒。
  • 多变量时要区分偏导与全导；共享参数的路径要相加（不是相乘）。

π_θ 的梯度靠它从损失一路传回 θ 的每个元素。

相关：前向传播、反向传播、log-softmax 的导数

前向传播

forward pass 微积分与自动微分
\(z_1,a_1\)
第一层的线性输出与激活
\(\mathcal{L}\)
损失值
\[ x\;\to\;z_1\;\to\;a_1\;\to\;z_2\;\to\;\hat y\;\to\;\mathcal{L} \]

从输入逐层算到损失；每一层只用上一层的输出。这一遍的目的就是拿到损失值。

  • 前向本身不产生梯度；要建计算图才能反向。
  • 中间激活必须留着给反向用——这就是训练显存远大于推理显存的根本原因（梯度检查点是用算力换显存）。

一次 DPO 更新里，对 π_θ 做 2 次前向、对 π_ref 也做 2 次（后者冻结，可预先缓存）。

相关：反向传播、链式法则

反向传播

backpropagation 微积分与自动微分
\(\frac{\partial\mathcal{L}}{\partial a_1}\)
损失的敏感度，从损失那端算起
\(w_1\)
第一层权重
\[ \frac{\partial\mathcal{L}}{\partial w_1}=\underbrace{\frac{\partial\mathcal{L}}{\partial a_1}}_{\text{从损失来}}\cdot\frac{\partial a_1}{\partial z_1}\cdot\frac{\partial z_1}{\partial w_1} \]

从损失出发把梯度往回传。每个节点的 \(\partial\mathcal{L}/\partial(\text{节点})\) 只算一次，被它的所有输入复用——这是动态规划，所以代价只有一次前向的约 2 倍。

  • 反向传播只算梯度，不改参数。 改参数是优化器（optimizer.step()）干的，这是最常见的误解。
  • 必须从后往前：链式乘积里第一个因子只能从损失那端算起。

一次 DPO 更新：π_θ 需要 2 次前向 + 1 次反向；π_ref 只前向（冻结 ⇒ 不进梯度）。

相关：前向传播、链式法则、梯度下降与 Adam

对数域技巧 log-sum-exp

log-sum-exp trick 微积分与自动微分
\(m\)
最大值，用于平移
\(\mathrm{logsumexp}\)
先指数、再求和、再取对数
\[ \mathrm{logsumexp}(z)=m+\log\sum_j e^{\,z_j-m},\qquad m=\max_j z_j \]

先减最大值再做指数，避免上溢。它是 softmax 的对数域兄弟。

  • 不能直接算 \(\log\sum_j e^{z_j}\)（会先 inf）。
  • \(\mathrm{softmax}=\nabla\,\mathrm{logsumexp}\)：softmax 就是它的梯度。
  • 几千个小于 1 的数连乘会下溢成 0，取对数后变成加法才安全。

log_softmax 与 logsigmoid 的内部实现；gold NLL 里「乘积变求和」也是同一件事。

相关：softmax、softplus、数值稳定性（上溢／下溢）

log-softmax 的导数

derivative of log-softmax 微积分与自动微分
\(\delta_{ky}\)
Kronecker delta（k=y 时为 1）
\(p_k\)
softmax 输出的第 k 个分量
\[ \frac{\partial}{\partial z_k}\log\mathrm{softmax}(z)_y=\delta_{ky}-p_k \]

输出层的误差信号是 one-hot 减 softmax；配上交叉熵后就是那句著名的 \(\partial\mathcal{L}/\partial z=\hat y-y\)。

  • 这个极简形式只在「softmax 输出 + 交叉熵」配对时成立；换成别的损失就不成立了。
  • 它是反向传播的起点，不是终点——从它开始才逐层乘到各层权重。

所有分类网络与语言模型输出层的梯度；DPO 里 σ 那一支同理（K=2 特例）。

相关：链式法则、二元交叉熵 BCE、反向传播

数值稳定性（上溢／下溢）

numerical stability 数值与精度
\(e^{z}\)
指数函数，浮点范围有限
\[ e^{z}\ \text{上溢于}\ z\gtrsim 709,\qquad e^{z}\ \text{下溢于}\ z\lesssim -745 \]

浮点数的指数范围有限，所以一切含 exp 的式子都要想办法把指数挪到非正区间。

  • \(\log(\mathrm{sigmoid}(z))\) 在 z 很负时会变成 -inf——必须用 logsigmoid。
  • \(\log(\mathrm{softmax}(x))\) 同理，要用 log_softmax。

DPO 的实现要点：损失一律用 logsigmoid / log_softmax，不写嵌套的 log∘sigmoid。

DPO 损失

DPO loss 偏好优化
\(\beta\)
KL 强度（同时是温度），不是 margin
\(\Delta_{\mathrm{DPO}}\)
隐式奖励差（校正后的 margin）
\[ \mathcal{L}_{\mathrm{DPO}}=-\,\mathbb{E}\Big[\log\sigma\big(\beta\,\Delta_{\mathrm{DPO}}\big)\Big] \]

对「胜者胜」这个标签做二元交叉熵，喂进去的 logit 是隐式奖励差：\(\mathcal{L}=\mathrm{BCE}(\sigma(\beta\Delta),1)\)。

  • β 不是间隔阈值；σ 的中点固定在 Δ=0，均衡点的间隔由数据决定。
  • DPO 损失的最优参数没有闭式解，仍要 SGD——有闭式解的是「给定奖励时的最优策略」。
  • 标签恒为 1，所以不存在类别不平衡问题。

你的主线方法；梯度里 \(\sigma(-\beta\Delta)\) 是「当前把输家排在赢家前面」的概率，即权重。

隐式奖励

implicit reward 偏好优化
\(\hat r_\theta\)
由策略与参考策略的对数比反解出的奖励
\(\pi_{\mathrm{ref}}\)
冻结的参考模型
\[ \hat r_\theta(x,y)=\beta\log\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)} \]

奖励不是独立于策略的东西——给定最优策略，奖励可以被它反解出来。丢掉的那个 \(\beta\log Z(x)\) 只依赖 x，落在不可识别的规范自由度里。

  • 只在同一条 prompt 内可识别；跨 prompt 比较会差一个未知的 \(\beta\log Z(x)\)。
  • 奖励只在「同题差」意义下唯一，给它加任意只依赖 x 的函数都不改变偏好与最优策略。

DPO 推导第二步；它也可以直接当奖励模型用于 Best-of-n 重排或喂给 PPO。

margin 与 margin loss

margin / margin loss 偏好优化
\(m_\theta\)
序列 margin：两个回答的对数概率差
\(\Delta\)
margin loss 作用的自变量
\[ m_\theta=\log\pi_\theta(y_w\mid x)-\log\pi_\theta(y_l\mid x),\qquad \ell=\max\big(0,\;m-\Delta\big) \]

margin 是量（分数差），margin loss 是作用于这个量的损失。 前者不是损失函数。

  • 不要写「DPO 的 margin loss」——DPO 损失里没有可调的 margin 阈值。
  • hinge 有真空区（达标后梯度精确为 0）；softplus 永不归零，只是一直变小。
  • 真正显式带 δ 的偏好损失是 SLiC 那一支：\(\max(0,\delta-\log P(y_w)+\log P(y_l))\)，而且它不含 π_ref。

你们监控的 margin；注意它和 DPO 损失的自变量差一个 π_ref 的 margin（常数），而那个常数随 β 变。

配分函数与它的对消

partition function and its cancellation 偏好优化
\(Z(x)\)
归一化常数，对全部回答求和
\(r(x,y)\)
奖励
\[ Z(x)=\sum_y \pi_{\mathrm{ref}}(y\mid x)\exp\!\Big(\frac{r(x,y)}{\beta}\Big) \]

最优策略的归一化常数。它要对所有可能的回答求和，指数级不可计算。

  • DPO 没有算出它，只是借用了闭式解的形式做重参数化，让它在同题偏好对相减时对消。
  • 一旦需要奖励的绝对值（跨 prompt 比较、当全局奖励模型用），这个未知项就会回来。

DPO 能在没有奖励模型的情况下成立的关键一步；对消的原因是偏好对共享同一个 x。

序列概率的乘积分解

factorization of sequence probability 偏好优化
\(T\)
回答的 token 数
\(y_{<t}\)
该位置之前的 token
\[ \pi_\theta(y\mid x)=\prod_{t=1}^{T}\pi_\theta(y_t\mid x,y_{<t}) \]

整条回答的概率等于逐 token 条件概率的乘积；取对数后变成求和。gold NLL 就是 \(-\log\pi_\theta(y_w\mid x)\)。

  • 取负对数后是逐 token 求和，所以回答越长 NLL 的数值基线越大——跨长度的绝对值不可直接比较。
  • 实现里绝不能真去连乘（会下溢），一律取对数求和。

DPO 里那四个 log 概率都是这样算出来的；也是 gold NLL 这条保护信号的来源。

局部 token 信号

local token margin 偏好优化
\(z_t(k)\)
位置 t 上 token k 的得分（logit）
\(q_t\)
正确 token 相对最强竞争者的优势
\[ q_t=z_t(\mathrm{gold})-\max_{k\neq\mathrm{gold}}z_t(k) \]

关键位置上正确 token 相对最强竞争 token 的决策余量：\(q_t>0\) 恰好等价于该位置选对，\(q_t\) 的大小表示赢得有多稳。

  • 它是余量，不是概率——不要和 \(\mathrm{softmax}\) 输出的概率混。
  • \(q_t\) 大不代表整段回答概率高（那是 gold NLL 管的）；两者是两个层面。
  • 需要固定位置选择规则，并在独立新题上验证迁移效果。
